03 — Annotations · Each callout references the authoritative document section
1
The Surface — #0d1014, Nothing Else
Brand Identity §6.10 · §10.5 Inviolable I · UI Design §8.1
Focus Mode background is --color-bg-base (#0d1014) across the entire viewport. No other background value. No gradient. No vignette. No texture. The prose column has no visible border, no shadow, no container. The text appears to float directly on the surface. This is Inviolable I: the prose surface is always the lowest-noise surface in the application.
2
Prose Column — 620px Centred
Brand Identity §6.2 · §6.4 · UI Design §9.1
The prose column is max-width: 620px, centred horizontally within the viewport using auto margins. Side margins grow symmetrically on wide screens — the column never grows beyond 620px regardless of screen width. Font: Lora 400, 18px, line-height 1.85. Top padding: enough to place the active line at 42% of viewport height when typewriter scrolling is on. Bottom padding: 120px minimum — the author always writes into open space.
3
Breadcrumb — Ghost, Not Navigation
Brand Identity §6.10 · UI Design §8.1
Font: Inter 200, 11px, --color-text-muted. Position: absolute, top of viewport, centred. NOT clickable in Focus Mode. pointer-events: none — clicking anywhere in the upper area does nothing. The breadcrumb is a location marker only. Opacity: 0 while typing, fades to 0.2 after 3 seconds of inactivity via 800ms --easing-prose transition. Returns to 0.2 on any mouse movement. The maximum opacity in Focus Mode is 0.2 — it never becomes a full navigation bar. Format: Doc · Layer · Layer · Layer · Current.
4
Word Count — Observer, Not Monitor
Brand Identity §6.7 · UI Design §9.3
Font: Inter 300, 11px, --color-text-muted. Position: bottom of prose column, right-aligned, inside the column (not at viewport edge). Opacity 0 while typing and for 3 seconds after the last keystroke. Fades to opacity 0.4 over 800ms --easing-prose after 3 seconds of inactivity. On hover of the bottom area: opacity 0.9. With target: 87 / 400 — at/above target: first number becomes --color-accent (verdigris). No other notification that the target has been reached.
5
Esc Hint — Disappears, Does Not Return
Brand Identity §6.10 · UI Design §8.1
Font: Inter 300, 10px, tracking 0.12em, --color-text-disabled. Position: bottom-right of viewport, inside the prose column's right edge. Text: Esc to exit. Shown on Focus Mode entry. Fades to 0 after 5 seconds — does NOT return on mouse movement (unlike the breadcrumb and word count). The author should learn the shortcut from the first session. By the second session, the hint should not be needed and is never seen. A returning user who has forgotten can use ⌘K to search for exit.
6
Mouse Movement — What Changes and What Does Not
Brand Identity §6.10
On mouse movement: breadcrumb fades up to 0.2. Word count fades up to 0.9 if the mouse is near the bottom area. Esc hint does not return (already hidden after 5s). Nothing else appears. No toolbar. No navigation. No mode indicator. The maximum "active" state of Focus Mode still shows almost nothing. Mouse movement is not an invitation to add chrome.
7
Sentence Focus — The Active Sentence (100% opacity)
Brand Identity §6.6 · UI Design §9.4
The sentence containing the cursor: opacity: 1 — full visibility, no change from normal. Sentence boundaries: determined by punctuation (. ! ?) followed by whitespace or end of paragraph. The active sentence must feel completely normal — it is everything else that fades, not the active sentence that brightens. Transition: 200ms --easing-prose when the cursor moves to a new sentence.
8
Sentence Focus — The Three Opacity Levels
Brand Identity §6.6 · UI Design §9.4
Active sentence: opacity: 1. Adjacent sentences (±1 sentence above and below): opacity: 0.85 — still clearly readable, semantic context available. All other sentences: opacity: 0.55 — present and readable if the author looks, but not demanding attention. 0.55 is the minimum — do not use lower values. Below 0.55, faded text reads as disabled or deleted rather than background. Default state: Off. Opt-in via the three-dot menu in the prose editor. Available as a prominent toggle in the Focus Mode surface.
