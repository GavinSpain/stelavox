RuleCSSNotes
Breakpoint@media (max-width: 1024px)Applied in global stylesheet. All tablet rules live here.

Tree min-width.tree-panel { min-width: 260px; }Reduced from 320px desktop minimum.
Detail min-width.detail-panel { min-width: 280px; }Reduced from 320px desktop minimum.
Node row height.node-row { height: 44px; }44px is iOS HIG / Android Material touch target minimum. Desktop is 36px.
Focus Mode prose.focus-mode .prose-column { max-width: 560px; }560px — not 620px. This is a locked value. ~60ch at 18px Lora. ~32px margins at 768px viewport.
Header height.app-header { height: 44px; min-height: 44px; }Reduced from 48px to save vertical space on tablet.
Font sizesUnchangedDo not reduce font sizes on tablet — legibility is more important than density.
Features removedNoneTablet has full feature parity with desktop. No functionality is removed.
