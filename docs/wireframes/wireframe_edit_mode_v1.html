02 — Annotations · Each callout references the authoritative document section
1
Wordmark — Cinzel + Cormorant + Lozenge
Brand Identity §3.2 · §3.3 · §3.4 · §10.5 Inviolable III
STELA: Cinzel 500, 15px, tracking 0.18em, uppercase. vox: Cormorant Garamond italic 300, 17px, tracking 0.08em, opacity 0.82. Both on the same baseline. Hairline rule: 1px, gradient from --color-accent to transparent. Lozenge: 7×7px square rotated 45°, #3d7858, at rule origin. Cinzel appears nowhere else in the product UI — wordmark only. This is Inviolable III.

Header Breadcrumb
UI Design §4.1 · §9.4
Inter 300, 12px, --color-text-muted. Format: Project / Document / Ancestor chain. Active segment slightly brighter (--color-text-secondary). Clickable — each segment opens that ancestor in the detail panel. Separator: / at 40% opacity. Truncates with ellipsis on overflow.
3
Mode Tabs — Edit / Director
UI Design §2 · §4.1 · Brand Identity §7 · §8
Container: --color-bg-base background, 4px padding, 6px border-radius. Active tab: --color-bg-surface fill, --color-text-primary, Inter 500 12px. Inactive: --color-text-muted, Inter 400. Shortcut: ⌘. toggles Edit↔Director. Transition: 200ms --easing-smooth when switching. Focus Mode is NOT a tab — entered via ⌘Return, exited via Escape.
4
Left Sidebar — 220px fixed
UI Design §4.1 · §5.5 · Brand Identity §10.2
Width: 220px fixed. Background: --color-bg-surface. Right border: 1px --color-border-subtle. Collapsible to 48px icon rail (collapse trigger: chevron button at bottom). Two sections: Project Navigation (top) and Context Library (bottom, flex:1, scrollable). Context library collapses per-type with count badge. Progressive disclosure: context library counts do not expand on first load — user must seek.

Tree Toolbar — Search, Filter, View
UI Design §5.6
Height: 36px. Background: --color-bg-surface. Search input: flex:1, --color-bg-base, 22px tall, border --color-border-subtle, Inter 11px placeholder. Filter and View buttons: Inter 11px, border --color-border-subtle. Filter dropdown: by status, layer type, has-prose, locked. 6
Node Row Anatomy — 36px height
UI Design §5.1
Row height: exactly 36px. Structure: [indent][chevron 12px][type-icon 16px][name flex:1][status-badge 8px][wc-bar 36px][hover-actions]. Indent: 16px per depth level (compresses to 12px at depth 5+). Chevron: 8° animated on toggle. Type icon: 16px Lucide. Node name: Inter 400 12px, truncates with ellipsis. Hover actions fade in on hover: Agent button, Add child, More (⋯). Touch target on tablet: 44px minimum.
7
Active Node — Verdigris Left Border
UI Design §5.3 · Brand Identity §4.4 · §10.5 Inviolable II
Background: --color-bg-active-node (#1f2d45). Left border: 2px solid --color-accent (#3d7858). Name: --color-text-primary, Inter 500. This is the second sanctioned use of verdigris — the active node marks where the author is working. The four permitted uses: (1) wordmark lozenge, (2) wordmark rule, (3) agent-complete status, (4) prose cursor. Active node border also uses the accent. Treat as a fifth sanctioned use specific to the tree.
8
Agent Running State — Breathing Animation
UI Design §5.4 · Brand Identity §7.2
When an agent job runs on a node: the type icon gets a breathing animation — opacity: 1 → 0.4 → 1, 2s ease-in-out, infinite. Status badge changes to --color-agent-running (#2e5a90). In Director Mode with active workflow: step indicators ◌ ⟳ ✓ ✗ replace the status badge on affected nodes only. Animation is the only unsolicited motion in the tree. It is calm, not urgent.
9
Status Badges — Exact Colour Values
UI Design §5.1 · Brand Identity §4.3
Badge: 8×8px filled circle, right-aligned after node name. Values: draft: #4a6080 (blue-grey, neutral), in_review: #b87030 (amber, attention), approved: #3d7858 (verdigris — same as accent, intentional: completion = the mark that endures), locked: #6a3888 (purple) with lock icon replacing type icon. These are the CSS token values — do not use the old palette (#555d77, #c9882a, #3a8a5f).
10
Detail Panel Header — Breadcrumb + Tabs
UI Design §6.1 · Brand Identity §9 (Voice)
Node title: Inter 600 14px. Breadcrumb: Inter 300 11px --color-text-muted, each segment clickable (opens that ancestor). Tab strip: Inter 400/500 12px. Active tab underline: 2px --color-accent (verdigris). Comments tab: orange dot badge when unresolved comments exist. History tab: grey number badge when versions exist. Agent tab: only visible when node has content (progressive disclosure per Brand Identity §10.2).
11
Summary Editor — Inter (structural text)
UI Design §6.2 · §3.3.1 · Brand Identity §5.3
Font: Inter 400, 13px, line-height 1.55. Background: --color-bg-base. Border: 1px --color-border-subtle. Toolbar: Bold | Italic | Bullet list | Numbered list only — no headings, no colours. Auto-expands with content. Character count in bottom corner. This field uses Inter deliberately — it is planning text, not manuscript. The typeface distinction is the UX signal that you are outside the work, not inside it.
12
Prose Editor — Lora (manuscript surface)
UI Design §6.2 · §3.3.2 · §9.1 · Brand Identity §5.3 · §6.2
Font: Lora 400, 16px in panel (18px in Focus Mode), line-height 1.85. Column: max 620px (66ch at 18px). Background: --color-bg-base. Border: 1px --color-border-default (slightly stronger than summary). Left-aligned, ragged right, never justified. Paragraph gap: 1.25em margin-bottom. No first-line indent. Side margins: min 48px. Bottom margin: 120px minimum. The typeface change Inter→Lora is the primary mode signal. It communicates: you are inside the work.
13
Verdigris Cursor — Inviolable II
Brand Identity §6.3 · §10.5 Inviolable II · UI Design §9.2
Width: 2px. Colour: --color-accent (#3d7858 verdigris). Blink cycle: 600ms on / 400ms off. No blink while actively typing — blink resumes 1200ms after last keystroke. Height: cap height of current line (not full line-height). This is one of the Four Inviolables — verdigris marks the point of inscription, where the permanent mark is being made right now. Never use system default cursor in the prose editor.
14
Word Count — Observer, Not Monitor
Brand Identity §6.7 · UI Design §9.3
Position: bottom of prose column, right-aligned, inside column. Font: Inter 300 11px --color-text-muted. Opacity 0 while typing and for 3 seconds after last keystroke. Fades to opacity 0.4 over 800ms after inactivity (easing: --easing-prose). Hover: opacity 0.9. With target set: shows 87 / 400 — below target: first number in --color-text-secondary; at/above target: first number in --color-accent. The word count observes; it does not monitor.

The Three Inviolables — Claude Code Must Enforce These Throughout Brand Identity §10.5
InviolableRuleHow to check
I — Prose surface The prose editor background is always --color-bg-base (#0d1014 dark / #f2ede4 light). Never a lighter surface. Never elevated. Search codebase for ProseEditor background declarations — must all resolve to --color-bg-base.
II — Verdigris accent --color-accent (#3d7858) appears in exactly these places: (1) wordmark lozenge, (2) wordmark rule, (3) agent-complete status badge, (4) prose cursor, (5) active node left border. No other uses. Search codebase for --color-accent and #3d7858 — every occurrence must be one of these five. Any other use is wrong.
III — Cinzel Cinzel font appears only in the Wordmark component. Never in any other component. Search codebase for Cinzel — must appear in exactly one component file.
