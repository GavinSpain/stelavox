08 — Writer's eye review

What worked. Bracketed labels carry over from Edit Mode cleanly — the breadcrumb is now an actual orientation aid rather than a faint ghost. ⌘ ← / ⌘ → addresses the most-cited Focus Mode friction (sequential beats). Cursor blink-via-caret-color (CS v2.3 fix) means the text doesn't pulse with the cursor; only the cursor does. WordCount-goes-verdigris at target is the highest-value use of verdigris in this surface (use #6).

What I'd watch in real use.

  • F-1 — Breadcrumb opacity ceiling. 0.2 → 0.35 (steady) + 0.7 (hover). Component Spec §6.2 amendment required at consolidation.
  • F-2 — Beat navigation shortcut. ⌘ ← / ⌘ → for prev/next sibling beat; wraps to next/prev sibling-parent's first/last child at the boundaries. Keyboard-only; no visible button. New behaviour, not in current spec — would land in Component Spec §6.1 + Product Spec §3.x.
  • F-3 — Brand presence. None (Option G). Inviolable #1 stands.
  • F-4 — Position counter in breadcrumb. Adding "2 / 5" after the leaf-label (see E/F) helps the author know where they are in the parent. Worth keeping permanently, or only on hover?
  • F-5 — Nav hint visibility. Currently opacity 0.2 at rest, 0 while typing. Some authors will want to know the shortcut exists; others will hate the chrome. Tucking it bottom-centre between Esc (left) and WC (right) is the lightest placement.
  • F-6 — Selection tooltip Link prompt. Still window.prompt in code (SU-22 closed 3/5; prose-editor Link + Notes Link prompts remain). Not blocking Focus Mode but flagged for Phase 8 polish.
  • F-7 — Sentence Focus. Phase 8.9. Visual contract not designed here. When it lands, the active sentence is normal opacity and adjacent sentences fade to ~0.4 over 200ms. Don't design it in iter1 — that's Phase 8.9's wireframe.
  • F-8 — Typewriter scroll. Phase 8.10 (opt-in via prose-editor three-dot menu, Phase 8.8). Don't design it here.
  • F-9 — prefers-reduced-motion audit. Phase 8.11. Cursor blink should be reduced or disabled when set. Sentence Focus fades should respect it. Not in scope for this iter; flagged so the 280ms expo-out entry transition gets reviewed in 8.11.

09 — Decisions

Locked (no further iter needed unless you object)

  • ● Bracketed labels in breadcrumb. Same convention as Edit Mode tree — JetBrains Mono, 10.5px, 1px border, position number from nodes.order.
  • ● Inviolable #1 holds. Background --color-bg-base, no toolbar, no formatting chrome at rest, no brand mark, no panel divisions.
  • ● Inviolable #5 holds. SelectionTooltip is the only formatting surface — Bold · Italic · Link, no headings.
  • ● Lora 18px / 1.85 line-height for prose. ProseEditor §5.4 unchanged.
  • ● Cursor: 2px verdigris caret-color, blink-via-caret-color (no text fade). CS v2.3 §5.5 unchanged. Verdigris use #3 unchanged.
  • ● WordCount: 0 typing / 0.4 idle / 0.9 hover; goes verdigris at target. §5.7 unchanged. Use #6 unchanged.
