Annotations
1
Wordmark restored. "Stela" in Cinzel + "vox" in Cormorant Garamond italic, with a thin verdigris hairline rule and the rotated-square lozenge per Brand Identity §6.4. Currently the header just says "Stelavox" in plain Inter — no logo, no rule, no verdigris. This is the single biggest change to the chrome's "feel." Implementing the missing components/brand/Wordmark.tsx is the actual code change behind this.
2
Sidebar verdigris hairline. A thin vertical verdigris gradient on the sidebar's right edge — always visible, never loud. Anchors the brand identity in the chrome without competing with content. Candidate new verdigris use (Inviolable #2 currently locks at nine — this would propose use #10).
3
Recent Documents grid. Replaces the current "flat list of projects, mostly test fixtures" with a 3-column doc-card grid. Each card shows type, title, project context, last-edit timestamp, progress bar with verdigris fill, and a status line. The most-recent 2–3 documents land here; full list lives in "All documents."
4
Punchier status pips. 8px diameter (was 7px), brighter agent-running blue (#4d8fd6 vs #2e5a90), brighter review-amber (#e09040 vs #b87030), with a subtle outer glow + pulsing animation on the "running" state. Visible peripherally without being intrusive — this is the "match Claude's dot legibility" calibration.
5
"New document" card. Always visible, dashed-border, verdigris-on-hover. The next thing the author might want to do is one click away from first-load, regardless of whether they have one document or twenty.
6
Sandbox / test fixtures, folded. The 60+ exec-pw-* projects from Playwright runs are still accessible but hidden by default behind a disclosure. The author's dashboard surface is no longer dominated by test detritus on first load.

03 — Decisions surfaced by this draft
Brand chrome 5 decisions
Wordmark
NEW component at components/brand/Wordmark.tsx. Three size variants: sm (header 48px), md (compact), lg (empty state). Verdigris lozenge + gradient rule per Brand Identity §6.4. The text "Stelavox" in the current header is a deferred Phase 2 placeholder — implementing the spec'd component is the change.
Verdigris use list
Proposed additions to Inviolable #2: (#10) wordmark lozenge + rule (already in spec, just unrealised); (#11) sidebar right-edge hairline; (#12) "running" status pip + glow. The current nine are kept verbatim. This brings the count to twelve. Open: too aggressive? Or right? Hold on judgement until we see more wireframes — the count interacts with chrome you haven't seen yet.
Inviolable #1 scope
Scoped to ProseEditor + FocusMode only. Dashboard, edit-mode chrome, panels, modals, settings, admin — these can carry brand presence. The prose canvas itself remains lowest-noise.
Status pip palette
Bump saturation on the "attention/motion" tones: --st-running-bright #4d8fd6 (was #2e5a90), --st-review-bright #e09040 (was #b87030). Pip size 7px → 8px. Add subtle outer glow on active states + pulsing animation on agent-running. Approved/complete stays at current verdigris (settled states should not seek attention).
Cmd+K chip
Visible affordance in the header right-side. Hint to power users; doesn't compete with the wordmark. Verdigris-on-hover. (Command palette implementation is 8.1 — this is just the chip.)
Dashboard structure 4 decisions
Greeting
"Good [time], [name]." in Inter 600 24px. Sub-line: "N projects · M documents · K briefs active". The current dashboard has no warmth at first load — this is the cheapest, highest-impact change.
Recent Documents grid
3-column grid, max 4 cards including a "New document" placeholder. Each card: type label, title, project + last-active, progress bar with verdigris fill + percent label, status pip + sentence. Hover: verdigris border + 1px translate-up.
Projects list
Below the Recent Documents grid. Per-row: project icon (verdigris-on-verdigris-muted square), name, meta line, doc count, chevron. Verdigris-on-hover border. Only "real" projects appear here.
Test fixtures
Projects matching ^exec-pw-.* or other test patterns are folded behind a "Show N test / sandbox projects" disclosure. Still accessible, no longer dominant. Pattern list is configurable via platform_config (suggested key dashboard.sandbox_project_patterns).
Empty state 3 decisions
Wordmark large, centred
Same Wordmark component at lg variant. Verdigris elements are now visible at a size where they read as a logo, not a decoration.
Tagline
"The author's thought should arrive on the page undistorted." Cormorant Garamond italic. This is the project's stated philosophy — the empty state is the right place for it.
CTA
"Create your first project" — verdigris button with a slight verdigris-tinted shadow (gives the button presence without being garish). This is verdigris use #7 (affirmative-action) — within the existing family.
Open questions your call
Q-1 — Wordmark variant
Cinzel + Cormorant Garamond pairing is per the existing spec. Want me to explore an alternative (e.g., both in Cinzel; or wordmark as a glyph-only logomark instead of typeset text)? Current draft holds to the spec.
Q-2 — Sidebar hairline opacity
Current draft: gradient (transparent → 35% → transparent), top-to-bottom inset. Subtle but visible. Try louder (50%) or quieter (25%)? Or different position (left edge of main panel instead)?
Q-3 — Status pip glow
Currently only the "running" pip carries a glow + pulse. Should "review needs attention" also glow (statically)? Or keep glow exclusive to motion-active states?
Q-4 — Project icon
Current draft uses ◆ (diamond glyph) in a verdigris-muted square. Alternatives: project-type icon (book/paper/board), first letter of project name, abstract per-project colour seed. Diamond is "Stelavox-branded neutral" — neither warm nor cold.
Q-5 — Settings link prominence
Per your direction, Export lives in Settings (gDrive setup, schedule, etc.). Should the header Settings link become a button-like affordance, or stay as plain text? Plain text in current draft.
