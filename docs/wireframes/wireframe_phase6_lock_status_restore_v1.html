Decisions locked in this session (no further input needed)
D1 · Three categories, three vocabularies. Only Category 1 (Author Lock) uses the word "lock" in UI. Category 2 (Edit Session) says "editing" / "in use". Category 3 (Agent In-Flight) says "queued" / "working" / "ready for review". Locked.
D2 · Per-node locks, no implicit cascade. Locking Act 1 protects Act 1's content + structure + status + tree position only. Existing unlocked descendants remain writable. Bulk-with-descendants creates N independent records sharing bulk_operation_id. Locked.
D3 · Lock proposal does conflict check. If pending jobs target the to-be-locked node(s), lock fails with options: cancel jobs (in Scheduler) or retry later. No proceed-anyway. Locked.
D4 · Lock reason optional with suggestions. Free-text input. Four launch suggestions in platform_config. Empty reason allowed. Locked.
D5 · Force-unlock available, audit-logged. Org owner only. Recorded in audit_log with action force_unlock + target node + reason (optional). Surface at /settings/locks. Locked.
D6 · Auto-lock on completed-pending-review is indefinite. Also serves as the author's "review needed" backlog signal. No timeout. Author controls when to Accept/Dismiss. Locked.
D7 · Status reduces to 2 values. draft + approved. Bidirectional free flips. No state machine. No audit-log entry for status changes (updated_at + last_modified_by suffice). Locked.
D8 · Restore is additive and content-only. Creates new version (change_reason='restore_from_vN'), preserves all history, overwrites summary/prose/notes/metadata only. Preserves name/tags/structure/status/lock. Locked.
D9 · Restore button uses destructive token + confirmation modal. Red token on the button; explanatory modal teaches the additive-history model. NOT verdigris. Locked.
D10 · Restore on version conflict returns 409. No proceed-anyway. Author refreshes, decides again. Maintains author's mental model integrity. Locked.
D11 · Unified write-gate RPC. Every write endpoint routes through check_node_writable(node_id, user_id) which checks all three lock categories. ancestorChainLocked helper drops everywhere. Locked.
