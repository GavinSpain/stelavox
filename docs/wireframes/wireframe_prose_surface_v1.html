The Inter→Lora boundary is the product's primary UX signal. It communicates silently: you are now inside the work, not outside it managing structure. This boundary must be absolute — no Lora in structural fields, no Inter in prose fields. The font change replaces the need for a mode indicator, a label, or a tooltip. Serious writers will feel this immediately. Most users will feel it without knowing why.

05 — Annotations
1
Dark Mode — Background & Text
Brand Identity §4.2 · §4.3 · UI Design §3.2.1
Background: --color-bg-base (#0d1014) — the warm near-black chosen specifically to prevent halation. NOT #000000. Text: --color-text-primary (#ecf0f5) — NOT #ffffff. The combination produces 14.8:1 contrast: above WCAG AAA (7:1), below the halation-producing 21:1 maximum. This specific pairing was chosen after research showing ~47% of users have astigmatism which causes pure-white-on-black text to blur.
2
Typography — Why These Exact Values
Brand Identity §6.2 · §5.3 · UI Design §9.1
18px: Optimal range for sustained screen reading is 16–18px. 18px is the generous end — appropriate for a writing surface where the author may spend hours. 1.85 line-height: Standard recommendation is 1.7–1.8. 1.85 is slightly more open specifically because this is a writing surface, not a reading one — the two-line working zone (current line + line above) benefits from extra breathing room. 620px / 66ch: Bringhurst's ideal, confirmed by Ruder (1967) and Baymard Institute research. The scientific sweet spot for comfortable saccadic reading rhythm.
3
Light Mode — Parchment, Not White
Brand Identity §4.3 · §4.5 · UI Design §3.2.2
Background: --color-bg-base light (#f2ede4) — warm parchment, not #ffffff. Text: #1e1a12 — warm dark ink, not #000000. Same halation principle as dark mode: maximum contrast is not optimal contrast. The parchment connects to the brand's historical reference — vellum, the surface that has carried important writing through time. The cursor in light mode: --color-accent light (#254a38) — deep verdigris, visible against the warm background.
4
Paragraph Spacing — No Indent
Brand Identity §6.2 · UI Design §9.1
Paragraph gap: 1.25em margin-bottom = 22.5px at 18px base. No first-line indent. First-line indentation is a print convention designed to save space on tightly-leaded pages. On screen at 1.85 line-height, the generous leading already creates clear paragraph separation. An additional indent would feel academic and cluttered. The paragraph space alone provides all the separation needed.
5
Word Count — Position and Philosophy
Brand Identity §6.7 · UI Design §9.3
Positioned inside the prose column, right-aligned, below the last line of text. Inter 300, 11px, --color-text-muted. Invisible while typing. The word count observes; it does not monitor. The verdigris colour change at target (--color-accent on the first number) is the only notification that a target has been reached — no toast, no sound, no pulse. The colour change is enough. An author who has set a target will notice it.
6
The Typeface Signal — The Most Important Detail
Brand Identity §5.4 · UI Design §3.3.2
The transition from Inter to Lora is not a visual flourish. It is the primary signal that the author has moved from structure into manuscript. This boundary must be absolute — enforced at the component level, not at the page level. The SummaryEditor component always uses Inter. The ProseEditor component always uses Lora. There is no shared base component that allows either font to leak into the other context. The ProseEditor in Edit Mode uses 16px; in Focus Mode 18px — same typeface, same line-height, slightly larger at full screen.
