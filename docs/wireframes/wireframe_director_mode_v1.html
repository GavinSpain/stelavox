04 — Annotations
1
Sidebar Collapses to Icon Rail in Director Mode
UI Design §4.2 · §7.1
When Director Mode is entered, the sidebar auto-collapses from 220px to a 48px icon rail. This is automatic — the author does not trigger it. The space is needed by the Director panel. The rail shows project icons only; the context library is hidden (available via clicking the icon to expand temporarily). The transition: 200ms --easing-smooth, sidebar width animates, Director panel slides in from the right simultaneously.
2
Director Panel Width — 55% Maximum
UI Design §7.1 · Brand Identity §7.3
The Director panel never exceeds 55% of the viewport width. The node tree must always remain visible — the author needs to see what the Director is talking about as it talks. At 1280px: Director panel max 580px, tree gets the remaining ~652px (minus 48px icon rail = ~604px usable). At narrower viewports (1024–1279px): Director panel may compress to 50% to preserve tree legibility. Never let the Director panel push the tree below 300px.
3
Director Mode Indicator — Animated Dot
UI Design §2.3
The Director tab in the mode switcher shows an animated blue pulse dot when an operation is actively running. The dot is --color-agent-running (#2e5a90), 6px diameter, breathing animation (opacity 1→0.6→1, scale 1→0.8→1, 1.5s ease-in-out). It appears only during active execution — not during normal conversation or planning. When execution completes, the dot disappears immediately.
4
Workflow Step Indicators Replace Status Badges
UI Design §5.4 · §7.2 · Brand Identity §8.3
During a Director workflow, the standard status badge (8px circle) on affected nodes is replaced by a workflow step indicator (16px, 3px border-radius). The four states: ◌ pending (surface bg, text-m), ⟳ running (agent-running blue, breathing animation), ✓ complete (verdigris), ✗ failed (error red). After workflow ends: all step indicators are removed and standard status badges return with updated values.
5
Locked Nodes — Not Included, Plan Works Around
Product Specification §8 · UI Design §7.2
If the Director's plan would affect a locked node, the plan card displays a warning: ⚠ Chapter 7 is locked — not included. Plan works around it. The warning uses --color-status-review (#b87030) amber. The locked node receives no workflow step indicator — it is excluded entirely. Locked nodes are sacrosanct. The Director cannot modify them. This is not a soft constraint. No UI affordance should suggest it might be possible.
6
Director Header — ◆ Symbol and Document Tag
UI Design §7.1
Panel title: ◆ The Director. The ◆ is the Director's identity mark across all contexts — it appears on Director messages in the thread, in the panel title, and on the thinking indicator. Colour: --color-accent verdigris. The document tag (The Iron Veil) shows which document this Director session belongs to. One conversation per document — switching documents shows that document's conversation history. History button reveals previous sessions.
7
User Message — --color-bg-selected, NOT Verdigris
Brand Identity §4.4 · UI Design §7.2
User messages: --color-bg-selected (#1f2d45) background, right-aligned, border-radius 8px 8px 2px 8px. Never --color-accent-muted. A user message bubble carries no connection to the four verdigris categories (brand, inscription, completion, location) — using the accent here would be a spurious use. The blue-tinted selected colour is sufficient and appropriate for a message bubble. Font: Inter 400 12px (Director conversation is structural — never Lora).
8
Plan Card — The Trust-Building Mechanism
UI Design §7.2 · Product Specification §10
The plan card is interactive, not just text. Each step has a checkbox the author can uncheck to skip that step. When any step is unchecked, the Approve button changes from "Approve All" to "Approve Selected" — live, immediate. Edit Steps expands each step inline for the author to edit the agent instruction. Nothing executes until the author clicks Approve. The plan card must feel like a deliberate decision, not a confirmation dialog. Border-radius: 6px. Background: --color-bg-surface. Steps separated by 1px --color-border-subtle.
9
Input Area — @ Mention and Quick Actions
UI Design §7.3
Textarea: auto-expands 1–5 rows, then scrolls. Enter sends. Shift+Enter inserts newline. Typing @ opens a node picker (searchable, lists all nodes in current document). The selected node is attached as a reference — the Director receives context about that node along with the message. Quick action chips above the input are context-aware suggestions (change based on document state and conversation history). Font: Inter 300 12px. Placeholder: Inter 300, --color-text-disabled.
