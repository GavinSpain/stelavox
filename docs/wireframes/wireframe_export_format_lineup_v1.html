DR-042 · Export Format Lineup · v1.0 · 2026-06-13
What this covers. The reworked export modal locked 2026-06-13 (register v3.4). Four states: a Novel document (whole-document, no picker), a Series document exporting a publishing format (per-book picker), the resulting per-book jobs in the progress stack, and a runtime failure routed through the 9.E failure surfaces. Lineup: DOCX + EPUB are per-book publishing artifacts; Markdown (new) is the whole-document own-your-data backstop; Outline is the structural snapshot. JSON is removed (re-homed to DR-036 as export+import together). Export action stays neutral primary — not verdigris.

Annotations
1Format tiles — JSON is gone. Four tiles: DOCX, EPUB, Markdown (new), Outline. Markdown carries an always available badge — it can never be disabled, the guaranteed escape hatch. Selected tile uses --color-text-muted border + --color-bg-base fill (no verdigris).
2Profile unchanged from Phase 7 — filtered to the chosen format. Markdown manuscript ships with a built-in profile; no author-config needed to use it.
3Series document detected. The picker appears only when the document has more than one node at the Book layer and the format is a per-book publishing format (DOCX/EPUB). A Novel document (§01) skips it entirely.
4Book picker — deliberate pick. Nothing is checked on open (author's locked choice) — you must consciously select what you publish. Per-book counts (words · chapters) and a draft tag orient the choice. Select all is one click for the export-everything case.
5Filename preview. {Series} — {NN} {Book Title}.{ext} with a zero-padded ordinal so a multi-book drop sorts itself. Shown live as the selection changes.
6Export button reflects the count — “Export 2 books”. Disabled (muted) while zero are checked, enforcing the deliberate pick. Neutral primary token — not verdigris (export is not an agent-proposal trigger).
7Markdown / Outline = whole document. No picker — these are the take-everything formats. One .md for the entire series; tiny even for a 10-book epic (~9 MB), so it never hits a size wall.
8One job per selected book. Each carries export_jobs.root_node_id = bookId and renders that book's subtree only. They reuse the existing ExportProgressStack, per-job retry, signed URL, and history rows — the UI is essentially free.
9No silent failure. Every failure shows a concrete reason via the 9.E classifyFailure / FailureBanner surfaces, plus the recovery path. If a format is provably unrecoverable for a book (a hard limit the pre-flight missed), it is dropped from that book's options.
Decisions — locked at the 2026-06-13 design discussion
Per-book DOCX/EPUB; whole-document Markdown/Outline.Locked Publishing formats split by book; the take-everything formats stay whole-document.
Book picker = deliberate pick.Locked Nothing checked by default; Export disabled at zero. “Select all” covers export-everything.
Markdown manuscript = the backstop.Locked Structure + final prose only, no history, no internal ids. Always available; cannot be disabled.
JSON cut from V1.Locked Re-homed to DR-036 as a future export+import feature, shipped together. Removed from the modal + renderer.
Filename pattern.Locked {Series} — {NN} {Book Title}.{ext}, zero-padded ordinal.
Decisions — locked 2026-06-14 (wireframe approved)
D1 · Picker trigger rule.Locked Show the picker when the document has >1 node at the Book layer (covers both the “Series” layer-stack and a Novel document holding multiple Book siblings) — not keyed on document_type. Follows real structure, not the stack label.
D2 · Markdown placement.Locked Markdown manuscript ships as its own tile (clearest intent), not an “include prose” toggle on Outline.
D3 · Quick-export default.Locked Quick-export on a Series document produces the always-available Markdown (whole series) rather than opening the picker.
